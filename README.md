# Patak

**Live:** https://patak-eye.vercel.app/

A private PWA that tells my aunt which eye drop is next for my grandmother's right eye, and reminds her when a dose is due. See `docs/PROBLEM.md` for why, `docs/SPEC.md` for what, and `docs/tickets/` for the build order.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # schedule logic tests
npm run build   # what Vercel runs
```
